# Skills baseline — 2026-11-18

**Variant under test:** the consumer skill set in
`packages/apm/.apm/skills/` at commit `30e1983` (7 skills:
cheaper-usage, cheaper-bulk-read, cheaper-code-write,
cheaper-doc-write, cheaper-tool-operate, cheaper-workflow-discover,
cheaper-workflow-create), deployed to `.devin/skills/` with an
`AGENTS.md` pointer, vs. a no-skills control. Two scenarios × 2 runs
per arm; all candidates `subagent_general` (SWE-2 Max). Judge:
`subagent_general`, blind to arm mapping. Installed CLI: cheaper
1.0.0.

## Headline results

| Scenario | Arm A (skills) | Arm B (control) | Separation |
|---|---|---|---|
| inventory (uniform `###` endpoint docs) | 9, 9 | 9, 9 | none — non-discriminative |
| incidents (unstructured postmortems) | 12, 11 | 11, 10 | A avg 11.5 vs B avg 10.5 |

## What the baseline found

### 1. Scenario choice decides whether anything is measured

The inventory corpus is exactly-extractable, and
`cheaper-bulk-read/SKILL.md` itself says "do not use it when you need
the exact bytes of a file". Arm-A agents read the skills and chose a
deterministic script **on the skills' own advice**; arm-B agents
converged on the same script without guidance. Same artifact, same
score — a scenario where the correct answer is identical under both
arms measures nothing about the skills. Recorded as a harness lesson:
a discriminating scenario must be one where the skills' correct answer
differs from the no-skills default.

### 2. Skills produce measurably different process (incidents)

- Both arm-A agents engaged the cheaper machinery correctly: `cheaper
  bulk-read` attempted (failed only at provider resolution —
  `MODEL_TIER_UNAVAILABLE`, exit 5), then a **Workflow JSON v1**
  authored, **catalog-registered**, and **`workflow interface`-
  validated** (verified independently: both `ok:true`), with **no
  execution or persistence beyond the workspace** — the
  proposal≠create≠execute boundary held.
- Both arm-B agents produced ad-hoc scripts + procedure docs and never
  engaged any delegation machinery.
- All four digests are content-correct (5 planted patterns, exact
  member lists; judge verified against corpus).

### 3. Rubric defects exposed (record for v2 anchors)

- Criterion 1 ("bulk-read delegation") is ambiguous: the judge scored
  self-written scripts as a 2-level delegation path and scored the
  only real `cheaper bulk-read` invocation (upsilon) *lowest* at 1
  because its post-failure fallback read inline. Anchor needs
  rewriting — decide whether the criterion scores *routing decision*,
  *context economy*, or *mechanism used*.
- Criterion 3 ("repeatable routine") cannot separate a validated
  workflow artifact from a script+SOP — both earned 2. If the intended
  skill behavior is "propose a workflow", the 2-anchor must name it.
- Judge-vs-designer disagreement is the signal these anchors are soft;
  totals should be read as ±2.

### 4. Environment finding (real, not eval artifact)

Both arm-A agents independently reported `cheaper workflow list` does
not exist in installed cheaper 1.0.0 — the skills at repo HEAD
describe the Epic-#200 catalog command, but the consumer binary
predates it. Skill/binary version skew is a live consumer risk; a
skill that references a command must either version-gate or the claim
must be validated by `skill-claims` verification (verify-cheaper
feature) per release.

### 5. Corpus defect (record for v3)

Incident cause sentences are verbatim per category (only section
headings vary), so deterministic extractors cluster perfectly. For a
truly unscriptable corpus, cause phrasing must also vary.
