## Implementation

### Changes

### Decisions During Implementation

Copilot source は binary-free acquisition 非対応として扱い、archive/local sibling を保持する。

case-insensitive collision が原因と診断し、test env の表現を一つに揃えた。launcher 本体は変更していない。
